About this choice

sRGB is a common colour space for web images. Choosing it tells the existing image pipeline how to interpret this untagged export. It does not correct lighting or approve artwork colour. The choice applies only to the image(s) identified here.

Original files stay unchanged.

Technical details

Untagged images require an explicit sRGB assumption. Intake uses the existing non-destructive JPEG/WebP/AVIF pipeline; progress and errors appear below.

When adding a new primary image, the previous primary is kept as an alternate view.
