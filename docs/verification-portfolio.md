## Execution and qualification contracts

- **Tier 1 (iteration):** run affected test files with `PLAYWRIGHT_BROWSERS_PATH=/tmp/opencode/jordannesbitt-browsers node --test tests/<affected>.test.mjs`. `npm run test:tier1` provides only the frequently useful `catalogue.test.mjs` baseline; **it is not sufficient by itself for every edit**. Changes to framework/state/config additionally require `npm run state:check`. Negative cases and direct consumers must be added when affected.
- **Tier 2 (affected integration):** `npm run test:tier2:public` selects archive, catalogue, ingestion, moving-image, presentation, professional, publication, quality, smoke. `npm run test:tier2:content-tools` selects ingestion and pilot; `npm run test:tier2:studio` selects ingestion, pilot and studio. Run just the groups and boundary checks affected by stabilized changes; no blanket full-suite rule.
- **Tier 3, `published-site/v1`:** `npm run qualify:published-site` (alias `npm run verify`): strict DSM + project state check, actual Astro check/build, independent `release:check`, then `test:tier2:public`. Current contract: exact owner-approved public source and release identity, published-content/privacy isolation, SEO/routes/assets, media pipeline, public browser/a11y/keyboard/mobile and negative guards. Actual live edge, no-JS contact, mobile contrast, and owner judgment remain distinct external/human evidence under an authorized release; a local PASS alone is not deployment approval. No sanitizer, hardware or external provider check is automatically asserted by this local command.
- **Tier 3, `private-studio/v1`:** `npm run qualify:private-studio`: strict DSM + project check, Astro build, Studio/ingestion/pilot integration plus publication and quality cross-boundary checks. Current contract: persistent local private state, loopback trust boundaries, CAS/concurrent edits, preview, review/export safety, no private-media publication. An actual owner Studio human gate is never automated.
- **Diagnostic broad execution:** `npm test` is the existing unfiltered 11-file Node test runner. `npm run verify:all` preserves the former state+build+unfiltered suite. Neither is the automatic Tier-3 contract; use for investigations, unresolved impact boundaries, and separately justified full reviews. The historical `npm run verify` named in pre-2026-10-27 records meant that broader command; do not rewrite those results.

Node >=22.12 (previous tested runtime 22.23.3); npm dependencies from the lockfile; Playwright Chromium/Firefox shell binaries configured by `npm run browser:install`; private Studio test data must remain isolated scratch (never committed). Astro build output is a prerequisite for publication, quality and smoke assertions. The two named qualifications are intentionally different and may overlap in ingestion/publication-oracle tests.
